# Research artifact release

The separate reproduction-and-releases branch contains audited recovery/training/replay tooling. The original three primary checkpoint identities remain missing; replacement checkpoints are explicit opt-in models. Main and all manuscript, supplementary, figure, table, PDF and historical evidence files remain unchanged.

See reproduction/REPRODUCTION_REPORT.md, REPLAY_PROTOCOL.md, INVENTORY.csv, MODEL_INDEX.json, RESULTS_COMPARISON.csv and LICENSE_AUDIT.md. The public-eligible v1 assets contain99 best states (three new primary replacements and96 recovered ResNet18-based heads), plus48 additional optimizer/resume files and permitted derived numerical exports. Thirty-six Phikon states and their derivative archives remain local, with a metadata-only rights-review draft.

Use the exact code commit in the release manifest and the pinned packages in reproduction/requirements-v1.txt. The research tag is allowed to refer to the tested, unmerged PR commit; publication does not merge the PR. Restore instructions are in reproduction/README_RELEASE.md. Large assets are kept out of Git.

Real release asset URLs and actual download/clean-checkout receipts will be appended after the draft upload has been verified. No current public-release or fresh-hardware-validation claim is made by this staging document.
