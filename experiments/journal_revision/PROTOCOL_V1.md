This protocol is committed before calculating or inspecting any new outcome comparisons. Base main: 3f6afe393f04f02df17ba3229b9b4dc7c889971a. Original arXiv v1, its 29 publication targets, exports and historical checkpoints remain immutable. All added analyses are post-v1 robustness/development analyses; Wu/Bassiouni have already been examined and are not new blind validation cohorts. No significance claims or model superiority are assumed.

## A: matched anchor-only comparisons

Use all existing random V1 mask trajectories, seeds 0-9, budgets 0.10/0.20/0.40, original observed prefix order and all original hidden targets. Fixed candidates: nearest anchor; uniform k=4,8,16,32; IDW k=4,8,16,32 × p=1,2,3; Gaussian k=8,16,32. Reference is IDW k16/p2. Report all 20 candidates; no external winner selection. No comparator receives images or hidden labels. Distances use original cKDTree nearest ordering, round to six decimals, inverse weights floor 1e-6 um, and use all anchors if fewer than k. Gaussian bandwidth is the median distance from observed anchors to their min(k,n_observed-1)th OTHER observed neighbor, floored at 1e-6; with one anchor use 1e-6. Weights are evaluated stably by subtracting each query's minimum squared distance before exponentiation (equivalent normalized Gaussian weights). No bandwidth selection uses outcomes. Harmonic extension is SKIPPED in V1 to prioritize interpretable stable baselines and avoid solver/model-selection additions; a future extension requires a new exploratory protocol.

## B1: operator × historical protocol

For every existing random V1/V2 mask at all three budgets, evaluate k16 IDW p2 and uniform k16 on that mask's exact observed/scored sets. V1 scores all hidden; V2 scores its existing forbidden region, with three original geometries. Pair operator effects within exact mask/scoring support. Historical V1/V2 differences still combine geometry and scoring support and cannot be called causal geometry effects.

## B2: identical-target placement control

For each section choose the central (geometry index 1) original PCA-coordinate compact region R containing floor(0.4N+0.5) locations. Central-only is predeclared to bound compute, not selected by outcomes. Fix H as floor(0.2|R|+0.5) locations (at least 1) drawn without replacement from sorted R indices using a seed derived from SHA256('H|'+patient) first eight bytes little-endian. H is about 8% of section and remains hidden in every condition. Distributed anchors are eligible at every non-H location, including R\\H; region-exclusion anchors are eligible outside R. For each condition use RNG seeds 0-9 and nested prefixes with floor(bN+0.5) anchors at b=0.10/0.20/0.40. Same seed and count, same H, different permitted pools. If capacity is insufficient, record that patient/budget as capacity-excluded for BOTH conditions; never reduce one group's count alone. Run k16 IDW p2 and uniform k16. Spatial FPS is secondary and SKIPPED for this first random-placement protocol, avoiding an additional analysis family. Persist R,H,anchor indices and barcodes before scoring. Report all paired r/MSE/MAE and nearest-anchor distance changes, plus occupied-bin error/support in [0,150),[150,300),[300,600),[600,1200),[1200,2400),[2400,infinity). No outcome-derived boundaries or tissue annotations.

## Metrics, pairing and uncertainty (C)

Reuse core.gene_metrics: undefined constant correlations at range <=1e-12, average ranks for Spearman ties, panel median defined gene Pearson/Spearman, panel mean MSE/MAE and valid-correlation counts. Average seeds within patient/geometry, then geometries equally within patient. Pair methods/designs within patient and exact comparable conditions before summarizing patients. Primary effects: median paired delta Pearson, delta MAE (candidate-reference; negative improves), relative MSE=(candidate-reference)/reference (negative improves). Report fraction improved and finite paired n separately. Do not replace undefined correlations with zero. For Bassiouni use patient-level percentile bootstrap with 10,000 resamples and RNG seed 20261101; statistic is median paired effect, resampling patients as whole units. Each contrast uses the same fixed RNG initialization. No p-values/multiplicity claims; intervals are descriptive post-v1 robustness summaries across a declared candidate grid, not simultaneous confidence bands. Wu: print all three patient deltas, no primary bootstrap claim. Do not pool cohorts. Reanalyze frozen v1 patient-level source rows separately and label them original-export reanalysis; use no aggregate plot values to fabricate new predictions.

## Verification and stopping

First run synthetic/API/leakage tests, then recover one real section and verify at least one original k16/p2 run against historical per-run/per-gene metrics (rtol/atol 1e-10 for summary/metric arrays; report max differences; near-zero tied-rank sensitivity separately, never silently change the protocol). If incompatible, stop affected new comparisons and diagnose. At every molecular call select observed vectors before prediction. Corrupt ALL unobserved labels, including V2 unscored rows, to NaNs/random values and require identical predictions. Store hashes of original masks, ordered gene/barcode arrays, inputs, protocol commit and current code. Never execute historical run/verify scripts.
