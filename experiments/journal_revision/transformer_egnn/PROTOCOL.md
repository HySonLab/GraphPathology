## Questions and candidates

Test H1 bounded nonlocal context, H2 explicit relative geometry/latent equivariant coordinates, H3 incremental images with the same measured anchors, and H4 topology specificity. No benefit, novelty, biological correlation, end-to-end equivariance or cost savings is assumed. Cite Rampasek etal NeurIPS2022 (arxiv2205.12454) and Satorras etal ICML2021 (PMLR139:9323–9332). Our compact implementation is GraphGPS-inspired, not an exact GraphGPS reproduction.

Exactly16 new configurations × seeds0/1/2 =48 fits:
- GraphGPS-inspired: full, nonlocal-disabled/local-only, no-relative-distance, self-only, spatial-assignment shuffled, and degree/length-bin matched rewiring. Each has121,018 nominal parameters. Width64, two blocks, four heads, dropout0.1. Local-only retains the same trainable attention projections but restricts each query to self plus at most7 capped-Delaunay neighbors (8 padded slots); it serves both the no-nonlocal and comparable-capacity local-only ablation. Full attention has32 deterministic farthest-point physical-coordinate landmarks. No dense NxN tensors. Complexity O(E d + N L d + N d²), L<=32, local K<=8. Relative distance is log1p(distance_um/250); local eight-RBF centers0..1,width0.15; attention eight-RBF centers0..4,width0.5. No-relative ablates distance gates/biases; graph and landmark selection still carry implicit geometry, so it is not called coordinate-free. Self-only has reduced effective function class despite equal nominal parameters.
- Distance-aware invariant fixed-coordinate model87,154 parameters; actual latent-coordinate E(2)-EGNN87,282; distance-disabled fixed-coordinate87,154; latent-model self-only, shuffled and degree/length-bin controls87,282 each. Two64-wide message blocks, SiLU, LayerNorm, dropout0.1. Edge messages use h_i,h_j and eight RBFs of squared normalized separation (centers0..4,width0.5). Node update is residual MLP on self and mean edge messages. Latent update is mean 0.1*tanh(phi_x(m_ij))*(p_i-p_j), phi_x64→1 initialized N(0,.001); only internal centered coordinates in250um units move. Physical coordinates/graphs/masks/anchor distances never move. Fixed-coordinate is accurately called distance-aware invariant/EGNN-inspired; it has no coordinate-update map. Latent vs fixed differs by128 parameters; disclose mismatch. The final coordinate update need not affect the scalar readout directly. Only scalar expression conditional on frozen embeddings is invariant; no image-pipeline E(2) claim.
- Fresh matched local128, mean128, GCN128 and SAGE67 baselines:72,114/72,114/72,114/72,075 parameters, respectively, with the same new full-section optimization budget. Also retain/reuse all30 frozen journal-v2 fits as separate stronger-training-budget references; never relabel them as fresh matched fits. No-image arms are fixed IDWk16p2 and uniformk16.
