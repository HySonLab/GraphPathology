3. CHECKPOINT ORGANIZATION
==========================
Use checkpoints/ as the single top-level home for archived experiment stages,
model states and their inventories. Here "checkpoint" includes both the C0-C10
research stages and serialized learned model parameters. Handle both meanings.

A practical target layout is:

  src/graphpathology/         maintained, importable scientific code and CLI
  configs/                   current, portable reproduction configuration
  scripts/                   small maintained entrypoints and publication tools
  tests/                     the supported test suite and tiny fixtures
  docs/                      methods map, data guide, reproduction and test reports
  manuscript/                supplied article/SI sources, figure scripts and exports
  checkpoints/
    legacy/                  immutable historical stage tree
      C1/ ... C10/
      reports/C0/
      ...                    original shared source/configuration records needed
                             to interpret or verify historical source hashes
    models/                  canonical locations for original fitted model states
    manifest.csv             asset identities, availability and checksums
    path_map.csv             original path -> canonical current path
    README.md                meaning of the archive and how to obtain model states
  data/                      configurable raw/processed/cache inputs, as appropriate
  outputs/                   new reproductions and bounded test outputs

Preserving original relative paths under checkpoints/legacy/ makes old source and
manifest relationships easier to interpret. If a cleaner alternative layout is
chosen, supply a complete resolver/path map and demonstrate that it preserves
the same assets. Keep all staged checkpoint directories under checkpoints/.
Keep the public root focused on the maintained package and publication workflow.

Use git mv where appropriate. Preserve historical file bytes, identifiers,
timestamps, selected hyperparameters, split assignments and numerical values.
Do not regenerate historical locks or rewrite old JSON/CSV path strings merely
to match the new directory names. Resolve those paths through the migration map.
Store any newly calculated audit/migration report separately from the originals.
Some append-only registry records hash a recorded byte prefix, not the complete
current file. Preserve that prefix length and verify the declared hash scope; do
not substitute a whole-file hash or rewrite the original registry to force a match.

Copy/promote reusable implementations into the maintained Python package as
needed. Archived source remains the evidence for the old source hashes; new
maintained code gets its own version and regression tests. Do not compare a
refactored source file to an old source hash and then disable the check to pass.
Provide separate operations for verifying the archived bytes and validating the
current implementation. No Git checkout/reset or archive mutation is needed to
run ordinary tests or build the publication.

Classify .npz/.json files by content and purpose: a feature cache, prediction bundle,
scaler and learned parameter state are different resources. Inventory all original
fitted states, including supporting models, not only the three primary heads.
If a model is moved to checkpoints/models/, retain its original filename and a
mapping from its historical location. Avoid two divergent copies of one state.

Small original heads may be tracked directly if repository policy permits.
Use Git LFS or a documented download location for large assets where appropriate;

9. SCIENTIFIC INVARIANTS TO PROTECT
==================================
Use the manuscript's detailed Methods and Experimental setup as the complete
specification. At minimum, regression checks must protect the following:

Data roles and scoring
* HEST development: NCBI783/NCBI785 fitting, TENX95 validation, TENX99 evaluation.
* HER2ST's eight patients were reused for calibration development; their 40-gene
  intersection is distinct from the 50-gene primary analyses.
* Wu calibration: 1142243F, CID4465, CID4535. Wu evaluation: 1160920F, CID4290,
  CID44971. Bassiouni uses one preselected section from each of 22 patients,
  without refitting.
* Whole expression vectors are hidden. Fit scalers and choose hyperparameters only
  from the designated fitting/validation/calibration data.
* Preserve raw-count log1p and the development normalization; do not introduce
  library-size normalization, assay harmonization or patient reassignment.
* Preserve gene order and barcode alignment throughout all caches and predictions.

Networks and graphs
* Final image branch: frozen ResNet18, 512 features, training-fitted scaler,
  Linear(512,256), GELU, dropout 0.1, Linear(256,50) with biases; 144,178 parameters
  per head. Three original heads, inverse head-target scaling, equal averaging.
* Preserve the nominal 112-um crop, LANCZOS resize to 224 pixels, official resize
  to 256 pixels followed by a central crop to 224 pixels, and ImageNet normalization.
  Do not silently simplify the two-stage resize.
* Graphs are section-local and coordinate-only: union-symmetrized kNN6/cap 250 um,
  radius 150/250 um, or Delaunay/cap 250 um. No initial self edges in binary A.
* With D=diag(A1), P=(D+I)^-1(A+I) is the self-inclusive mean. Q uses symmetric
  degree normalization. R uses neighbor-only row normalization with a zero
  aggregate at isolated nodes. Inputs are PX, QX or [X,RX], after feature
  standardization.
* One graph aggregation followed by the MLP; no added learned adjacency, attention,
  extra graph layers or GraphSAGE post-update normalization. Mean/GCN 512->128->50
  have 72,114 parameters; GraphSAGE 1024->67->50 has 72,075.
* Frozen Phikon uses the final normalized 768-dimensional CLS representation.
  Local/spatial head choices and topology controls remain the documented
  development comparisons.

Molecular reconstruction, calibration and metrics
* Up to 16 observed anchors. V1 uses inverse-distance-squared interpolation; V2
  uses an equal-weight neighbor mean. Preserve distance rounding/floors.
* V1 scores all hidden locations. V2 forbids a contiguous 40% region, samples
  anchors outside it and scores that region. Preserve the three geometries,
  whole-section budgets, rounding and nested random trajectories.
* Final fusion = 0.8 molecular + 0.2 calibrated image. The raw image-only comparator
  is different from the calibrated image term. Reuse source/Wu constants for
  Bassiouni. Patient-weighted moments are not pooled spot-weighted moments.
* The sparse learned comparator is residual ridge regression, 34 covariates plus
  an unpenalized intercept per gene, alpha 10000 under the summed-error objective.
  Preserve P and P^2 observed masses/messages and the n300/16 covariate, including
  its denominator 16 when fewer anchors exist.
* HER2ST fixed-fusion calibration and selected-fusion analyses are distinct.
  Preserve patient folds, target transformations and selection. Gate variance
  uses destination-transformed expression, population variance across up to 16
  nearest anchors, then the gene mean; the count within 600 um is a different feature.
* Preserve patient-first aggregation, gene medians versus means, mean/median
  distinctions between figures, undefined constant correlations and tied ranks.
  A median paired effect is not the difference between separate cohort medians.
* Do not change negative-control definitions or turn the mixed graph/fusion
  findings into a claim of demonstrated GNN superiority.
