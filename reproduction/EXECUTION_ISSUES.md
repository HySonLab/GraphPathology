# Execution issues retained transparently

The first Tier B evaluation stopped before producing predictions or metrics because its new alignment assertion mistakenly cast external reference targets to float32. Source HEST C0 targets are float32, whereas external C9/C10 targets and their recovered feature caches retain float64. The cache and independently reconstructed external targets agree exactly in float64. The assertion was corrected without changing data, predictions, models, thresholds, fitting, or the historical pipeline; a regression test rejects premature external rounding. The empty tier-b-v1 directory and failure log are retained locally. All actual Tier B outcomes use tier-b-v2, the same single three-seed training run and the locked original evaluation design.

The first recovered-state verification completed the 78 minibatch/advanced forwards but stopped when it looked for a reused ResNet state's numerical export under the later matched-study directory. Reused states retain their original export paths. Reference resolution now checks those immutable original paths; unselected validation-only trial states without historical external exports receive safe real-forward verification only, explicitly marked PARTIAL. No reference is fabricated and no candidate is reselected. A regression test covers reused paths and absent validation-only exports; the completed verification is tier-c-v2.

The first completed recovered-weight replay used four Torch threads uniformly. Strict 1e-10 comparisons then exposed float32 reduction sensitivity: up to 6.0813e-8 in a panel median correlation and 1.1137e-8 in a median MSE; scientific rounded effects agreed. The immutable original extension COMPLETE.json records explicitly specify one inference thread, while later matched Phikon scoring used four. A single corrective replay now reads those archived runtime settings before each forward (default four only where no specific inference override exists). The original four-thread outcomes remain in tier-c-v2 and matched-v1 as sensitivity evidence. No weight, input, model selection, metric, tolerance or training budget changed; no additional model was fitted. Corrected runtime results are tier-c-v3 and matched-v2. A regression test covers archived thread restoration.
